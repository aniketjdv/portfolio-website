1.Project Overview

The Personal Portfolio Website is designed to showcase my profile, technical skills, projects, and contact information in a professional and user-friendly format.

The website provides information about my background as a developer, highlights the projects I have built, and allows recruiters, clients, and other developers to connect with me.

The website is developed using HTML, CSS, and JavaScript, with a responsive layout and light/dark theme functionality.

2.Tools and Technologies Used

HTML5: Structures the web pages and their content.

CSS3: Handles styling, layouts, responsiveness, and visual design.

JavaScript: Adds interactive features, such as mobile navigation, theme switching, and dynamic content.

Visual Studio Code: Used to write and manage the project code.

Git and GitHub: Used for version control and project hosting, if configured.
